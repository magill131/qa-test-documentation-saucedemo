# BUG-002: problem_user: Add to cart does nothing for three products

- **Severity:** High
- **Priority:** P1
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-02](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `problem_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `problem_user` and start with an empty cart
2. Click Add to cart on all six products, one after the other
3. Watch the button text and the cart number after each click

## Expected result

Every click changes the button to Remove and raises the cart number by one, ending at 6.

## Actual result

Sauce Labs Bolt T-Shirt, Sauce Labs Fleece Jacket and Test.allTheThings() T-Shirt (Red) stay on Add to cart and the cart number does not change. Only the other three products are added and the cart ends at 3.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`problem_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

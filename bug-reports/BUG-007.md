# BUG-007: error_user: Remove does nothing on the Products page

- **Severity:** High
- **Priority:** P1
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-08](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `error_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `error_user`
2. Add Sauce Labs Backpack, Sauce Labs Bike Light and Sauce Labs Onesie
3. Click Remove on each of the three

## Expected result

Each click changes the button back to Add to cart and lowers the cart number.

## Actual result

The buttons stay on Remove and the cart number stays at 3. No error message is shown.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`error_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

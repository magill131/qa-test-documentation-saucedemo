# BUG-005: performance_glitch_user: login takes about 5 seconds

- **Severity:** Medium
- **Priority:** P2
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-05](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `performance_glitch_user`, https://www.saucedemo.com

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in as `performance_glitch_user` and time how long the Products page takes to appear

## Expected result

The Products page opens in about the same time as for `standard_user` (under 2 seconds).

## Actual result

The Products page opened after 5012 ms. `standard_user` took 59 ms in the same run.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`performance_glitch_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

The time was measured in a browser pane that may run as a background page, so the exact number can be off. The gap to `standard_user` (59 ms in the same session) is far larger than any such error.

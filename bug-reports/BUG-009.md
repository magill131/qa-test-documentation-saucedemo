# BUG-009: error_user: Finish does nothing, the order cannot be completed

- **Severity:** Critical
- **Priority:** P1
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-10](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `error_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `error_user`, add Sauce Labs Backpack, Sauce Labs Bike Light and Sauce Labs Onesie
2. Go through checkout to the overview page
3. Click Finish (tried twice, with a wait of 2 seconds after each click)

## Expected result

The confirmation page opens and shows "Thank you for your order!".

## Actual result

The page stays on the overview (`/checkout-step-two.html`). No confirmation and no error message.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`error_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

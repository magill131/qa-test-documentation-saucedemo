# BUG-001: problem_user: every product shows the same placeholder picture

- **Severity:** Medium
- **Priority:** P2
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-01](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `problem_user`, https://www.saucedemo.com

## Steps to reproduce

1. Open https://www.saucedemo.com
2. Log in as `problem_user` with the password shown on the page
3. Look at the six product pictures on the Products page

## Expected result

Each product shows its own picture, as it does for `standard_user`.

## Actual result

All six products show the same picture, `sl-404-Cq1a9k9X.jpg`. `standard_user` sees six different pictures.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`problem_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

# BUG-010: visual_user: prices differ from standard_user and change on every login

- **Severity:** High
- **Priority:** P1
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-11](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `visual_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `visual_user` and read the six prices
2. Log out, log in as `visual_user` again and read the prices again

## Expected result

Prices are $29.99, $9.99, $15.99, $49.99, $7.99, $15.99, the same as for `standard_user`, every time.

## Actual result

First login: $35.56, $32.99, $68.74, $94.69, $40.95, $44.91. Second login: $49.87, $19.31, $37.65, $5.44, $84.51, $27.93. None match the standard prices.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`visual_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

The layout of the Products page for `visual_user` was not compared, because the browser pane reported a 0 x 0 window and the measured positions were not reliable.

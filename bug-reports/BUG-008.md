# BUG-008: error_user: Last Name is not kept at checkout

- **Severity:** High
- **Priority:** P1
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-09](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `error_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `error_user` and add Sauce Labs Backpack
2. Open the cart and click Checkout
3. Enter First Name `Jane`, Last Name `Doe`, Zip/Postal Code `12345`
4. Read the three fields, then click Continue

## Expected result

All three fields keep what was typed.

## Actual result

Last Name is empty after typing `Doe`. Continue still goes to the overview without a Last Name error.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`error_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.

The values were entered by a script that sets the field value and fires the input event. Typing by hand in Chrome should be checked once to confirm the same result.

# BUG-011: visual_user: Sauce Labs Backpack shows the placeholder picture

- **Severity:** Low
- **Priority:** P3
- **Status:** Open
- **Date found:** 2026-10-19
- **Found by test case:** [TC-SPECIAL-12](../test-cases/special-users.md)
- **Environment:** Chromium 152 (Claude desktop app built-in browser), Windows, user `visual_user`, https://www.saucedemo.com

## Steps to reproduce

1. Log in as `visual_user`
2. Look at the picture of Sauce Labs Backpack (first product)

## Expected result

The Backpack shows its own picture, `sauce-backpack-1200x1500-...jpg`, as for `standard_user`.

## Actual result

The Backpack shows `sl-404-Cq1a9k9X.jpg`, the same placeholder `problem_user` gets. The other five pictures are correct.

## Evidence

Read from the page while running the case (button text, cart number, picture file names, prices, page address). No screenshot was taken.

## Notes

`visual_user` is one of the demo users the site lists on its login page as a test account. The behaviour above is what the site does for this user.
